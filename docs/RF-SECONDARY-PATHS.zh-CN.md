# 无线路径物理模型：现状与未实现项

本文不是变更日志，而是 Aetherax 当前无线传播模型的边界清单：哪些已经做了、哪些还是
近似、哪些完全没有做。实现参考 `D:\Project\sionna-rt` 的 Sionna RT，但 Aetherax 是
二维平面上的实时热力图，不会直接移植 Mitsuba 3D 射线追踪。

## 1. 当前已经实现的链路

热力图对每个纹素按以下顺序计算：

1. 自由空间直射；
2. 单次镜面反射；
3. 单刃峰绕射；
4. 单次漫散射；
5. 各路径按功率相加；
6. 3×3 平滑后量化成色带。

### 1.1 直射

- 路径长度使用三维距离：水平距离 + AP/客户端高差；
- 路径损耗使用工程选择的 log-distance 模型：
  - `lineOfSight`
  - `office`
  - `closedPlan`
- 墙体损耗来自墙体掩码或矢量墙；
- 楼板损耗来自楼层材质和厚度；
- 客户端高度默认 1.5 m，可由工程设置修改；
- AP 安装高度、天花板高度和抬高面参与垂直距离。

### 1.2 反射

当前是**单次镜面反射**：

- 镜像法求反射点；
- 只接受落在墙段内、AP 与客户端在墙同侧的反射；
- 反射系数来自 ITU-R P.2040 平板模型；
- **只使用反射系数的幅度平方**；P.2040 的复数相位在功率合成阶段被丢弃（见 3.9）；
- 路径长度是 AP → 反射点 → 客户端的实际长度；
- 两段路径分别计算穿墙损耗；
- 反射面自身的墙损被排除，避免和反射系数重复；
- 反射点、路径长度、方向图都按实际几何计算。

### 1.3 绕射

当前是**带高度的竖直刃边绕射**：

- 每面墙的两个端点是从地面到墙顶的竖直刃边；
- ITU-R P.526 单刃峰公式；
- 沿刃边用最小路程求三维绕射点，AP/客户端高度不同时也能落到墙高范围内；
- AP → 刃峰、刃峰 → 客户端都检查可见性；
- 路径损耗使用 `d1 + d2` 的实际三维折线长度；
- 天线方向按 AP → 绕射点计算；
- 从 AP 侧可见、客户端侧也可见的候选刃峰中，取损耗最小的 **最多 4 条**，按功率相加；
- 直连路径墙体损耗超过 3 dB 后才逐渐计入；过渡函数是
  `gate = clamp((wallLoss - 3) / 6, 0, 1)`，即 3 dB 处为 0、9 dB 处为 1，中间线性。
  3 dB 和 9 dB 是经验值，不是 ITU-R P.526 的理论阈值；它们的目的是避免阴影边界出现硬缺口。

### 1.4 漫散射

当前是**一维墙面积分**：

- 每面墙按约 1 m 切段，每面墙最多 16 个面元；
- 每个面元面积按 `段长 × 楼层净高` 计算；
- AP 一侧不可见的面元不生成，客户端一侧不可见的面元逐纹素跳过；
- 使用 Sionna `DirectivePattern` 风格的方向图（`alpha = 4`），散射能量集中在镜面反射方向；
- 方向图按入射角归一化；
- 面元贡献按 `S · cos θ_i · f_s · A` 计；
- 各面元功率不相干相加；
- 材质 S 内置值来自 Remcom 5G mmWave office 示例的工程近似。

| 材质 | 2.4 GHz | 5 GHz | 6 GHz | 备注 |
|---|---:|---:|---:|---|
| Drywall | 0.05 | 0.10 | 0.12 | 60 GHz 示例为 0.2，按频段下调 |
| Concrete | 0.15 | 0.25 | 0.30 | 60 GHz 示例为 0.4 |
| Metal | 0.10 | 0.15 | 0.18 | 60 GHz 示例为 0.2 |
| Wood | 0.05 | 0.10 | 0.12 | 无实测值 |
| Glass | 0.02 | 0.03 | 0.04 | 无实测值 |
| Brick | 0.08 | 0.12 | 0.15 | 无实测值 |
| Door | 0.05 | 0.10 | 0.12 | 无实测值 |
| Virtual Partition | 0 | 0 | 0 | 零衰减隔断 |

这些是**工程预设**，不是测量得到的材料常数。Remcom 的 60 GHz 示例范围是 0.1–0.5；
当前表把 60 GHz 值按频段下调，避免直接把毫米波 S 套到 2.4/5/6 GHz。没有实测数据的
材质只用于给出数量级，不能当作验收依据。自定义材质显式填写
`scatteringCoefficient` 时，优先使用该值，不再套用频段预设。

### 1.5 天线

- 垂直切面用 `beamwidthDeg + aimDeg` 近似；
- 壁挂 AP 额外有水平方位角 `facingDeg`；
- 吸顶 AP 默认 `aim = 30°`；
- 没有导入厂商实测三维方向图。

### 1.6 功率合成

- 直射、反射、绕射、散射都按线性功率相加；
- 不做复数场相干叠加；
- 不做相位、极化或 MIMO 处理。

### 1.7 缓存与候选

- 反射/绕射/散射候选按 AP 预计算；
- 候选跨帧缓存；
- 反射候选墙多时按墙中点建均匀网格；
- 热力图按完整输入键做多楼层缓存；
- 绕射和反射的候选不是严格的三维射线追踪，只是二维几何候选。

## 2. 当前模型的整体边界

Aetherax 目前是：

```text
2D 平面掩码
+ 竖直墙体
+ 固定客户端高度
+ 2.5D 距离和高度差
```

不是：

```text
完整 3D 场景
+ 任意测量面
+ 多次散射
+ 复数场
```

## 3. 未实现或仍为近似的物理模型

### 3.1 三维几何与任意 radio map 面

**状态：未实现。**

当前没有：

- 墙体厚度方向上的真实三维几何；
- 墙高、窗台、门洞的完整三维形状；
- 地板、天花板作为可反射/透射的面；
- 家具、隔断、柱子的完整三维网格；
- 任意 mesh 作为 radio map 测量面；
- 3D 射线与场景求交。

Sionna 的 `RadioMapSolver` 可以把任意 mesh 当作测量面，每个三角形是一个 cell。
要做到这一点，仅“墙端点带高度”不够，还需要整个 3D 场景和 3D 路径求交。

### 3.2 多次反射

**状态：未实现。**

当前最多一次镜面反射。没有：

- 二次、三次反射；
- 多次反射路径的可见性；
- 多次反射的路径损耗累积；
- 多次反射的功率合成；
- 反射路径之间的相位关系。

在走廊、房间角落和金属表面附近，多次反射会明显影响阴影区和延迟扩展。

### 3.3 粗糙表面与 Angle-dependent 反射

**状态：部分近似。**

当前：

- 反射系数按 P.2040 平板模型计算；
- 只和材质、频段、入射角有关；
- 不建模表面粗糙度引起的漫反射比例；
- 不建模反射相位的随机化；
- 不建模交叉极化。

真实粗糙表面的镜面反射会随频率、粗糙度、入射角变化，并伴随漫散射。Sionna 用
有效粗糙度模型和散射系数描述这部分。

### 3.4 透射与折射

**状态：近似。**

当前：

- 穿墙损耗是按材质和频段的标量 dB；
- 楼板损耗按楼板材质和厚度；
- 不计算斜入射的 Fresnel 透射系数；
- 不计算墙内多次反射；
- 不计算折射角；
- 不区分墙体两侧的入射/出射介质；
- 不处理门窗洞口的几何绕射/透射组合。

Sionna 的 `RadioMaterial` 用 P.2040 的介电常数和电导率计算 slab 的反射/透射系数，
并考虑厚度和入射角。

### 3.5 三维楔形绕射

**状态：部分实现。**

当前已经把墙端点升级为从地面到墙顶的竖直刃边，并用最小路程求三维绕射点。
仍没有：

- 楔形两个面的夹角；
- 三维 Keller 锥的严格解；
- Fresnel 过渡区和阴影边界；
- 极化相关的绕射系数；
- 二次绕射。

因此：

- 上层/下层路径的绕射角只是近似；
- 斜向绕射的路径长度不是严格三维；
- 靠近墙端、墙角、窗边时误差会变大。

### 3.6 绕射的高阶路径

**状态：部分实现。**

当前会累加最多 4 条可见刃峰的绕射功率，不再只取一条。仍没有：

- 绕射后再反射；
- 反射后再绕射；
- 多次绕射；
- 绕射路径穿过其他墙后的衰减。

Sionna 的路径求解器可以组合 reflection / diffraction / diffuse 交互；Aetherax 目前
是“每种二级路径单独算”。

### 3.7 完整的漫散射模型

**状态：一维近似，未完成。**

当前：

- 使用 Directive（`alpha = 4`）；
- 一维墙段积分；
- 每个面元一个确定点；
- 没有相位；
- 没有交叉极化；
- 没有 backscattering；
- 没有真正二维墙面积分；
- S 有 2.4/5/6 GHz 的工程预设，但没有按粗糙度、含水率、入射角校准；
- S 的频段预设不是实测数据，60 GHz 示例只作为量级参考；
- 墙高使用楼层净高，未区分实际墙高。

Remcom 的示例使用的也是 **Directive** 模型；其参数还包括：

- 散射因子 S；
- 交叉极化比例；
- Alpha（前向波束宽度）；
- 可选 backscatter。

Sionna 的 `scattering_pattern.py` 提供 Lambertian、Directive 和 Backscattering 三种模式，
并做归一化。Aetherax 目前实现了 Directive 的一维近似版本，没有 backscattering 和交叉极化。

### 3.8 极化

**状态：未实现。**

没有：

- 垂直/水平极化；
- 交叉极化散射；
- 极化相关的反射/透射/绕射系数；
- MIMO 极化矩阵。

RSSI 规划可以暂时忽略极化，但这会使：

- 交叉极化链路预测偏差很大；
- 金属、玻璃、粗糙表面的散射量级偏差；
- MIMO 流数和相关矩阵无法评估。

### 3.9 复数场与相位

**状态：未实现。**

当前所有路径按功率相加。没有：

- 复电场；
- 路径相位；
- 多径相消/相长；
- 频率选择性衰落；
- 延迟扩展；
- 相干带宽；
- MIMO 信道矩阵。

对于只做 RSSI 覆盖规划，功率相加通常更稳健；如果要做 MIMO、OFDM 或精确 CIR，
必须改成复场模型。

### 3.10 噪声、干扰与 SINR

**状态：未实现逐点 SINR。**

当前：

- 热力图显示 RSSI；
- 覆盖判断使用固定覆盖门限；
- 噪声底和接收灵敏度只作为门限的基准；
- 同频干扰使用 AP margin 差和复用窗口；
- 没有逐点 `SINR = 信号 / (噪声 + 其他 AP 干扰)`；
- 没有按信道宽度、噪声系数、干扰功率计算 SINR；
- 没有把 SINR 映射到 MCS、速率或容量。

Sionna 的 radio map 直接使用：

```text
SINR = RSS / (N0 + Σ 其他 AP 的 RSS)
```

Aetherax 目前只有 RSSI 和覆盖率，容量模型是独立的客户端数估算。

### 3.11 天线与阵列

**状态：简化。**

没有：

- 厂商实测三维方向图；
- 天线方向图的频率相关数据；
- 阵列流形和相位；
- 波束赋形；
- 接收天线方向图；
- 天线效率、损耗、端口方向图；
- 天线倾角的机械/电子区分。

当前 `beamwidthDeg + aimDeg + facingDeg` 只是垂直/水平切面的解析近似。

### 3.12 移动性与多普勒

**状态：未实现。**

没有：

- 移动客户端；
- 时间变化；
- 多普勒频移；
- 动态遮挡；
- 人员/门/家具的运动。

### 3.13 室外与特殊传播

**状态：不在当前范围。**

没有：

- 地形；
- 大气吸收；
- 雨衰；
- 植被；
- 室外绕射/反射；
- 卫星/高空平台。

这些不是当前室内 Wi-Fi 规划的核心范围。

## 4. 未实现项的优先级

### P0：影响当前室内热力图可信度

1. **三维楔形绕射**
   - 竖直刃边和三维最小路程已实现；
   - 继续补楔形夹角、严格 Keller 锥和 Fresnel 过渡区。

2. **Directive 参数与交叉极化**
   - Directive 已实现一维近似；
   - 继续补 backscattering 模式、交叉极化比例和按频段/粗糙度的 S 校准。

3. **逐点 SINR**
   - 把噪声和同频干扰纳入着色；
   - 至少提供 RSSI / SINR 两种视图。

### P1：影响复杂户型

4. **二次反射**
   - 走廊、角落、金属表面附近；
   - 需要候选路径组合和可见性验证。

5. **斜入射透射**
   - 用 Fresnel slab 模型替代固定 dB；
   - 需要墙体厚度和入射角。

6. **二维墙面积分**
   - 在高度方向也采样，而不只是一维线积分；
   - 需要墙高和二维面元。

### P2：完整射线追踪能力

7. **三维场景 / 任意 radio map 面**
   - 地板、天花板、家具、mesh 测量面；
   - 3D 求交和 3D 路径。

8. **复数场、极化、MIMO**
   - 相位、CIR、MIMO 信道矩阵；
   - 计算量和数据模型都会显著增加。

## 5. 做这些事需要的前提

### 三维楔形绕射

- 墙高、墙厚；
- 墙端点的三维坐标；
- AP/客户端三维坐标；
- 刃边与射线的三维求交；
- 楔形两面夹角；
- 可见性；
- Fresnel/UTD 系数；
- 性能预算。

### 二维墙面积分

- 墙高；
- 法线；
- 面元划分；
- 每个面元的 AP/客户端可见性；
- 材质 S；
- 面积和路径长度；
- 相位或不相干功率的选择。

### 多次反射

- 候选路径枚举；
- 每次反射的可见性；
- 路径长度和墙损累积；
- 组合爆炸控制；
- 缓存/剪枝。

### 逐点 SINR

- 每个 AP 的发射功率；
- 噪声系数和信道宽度；
- 同频/邻频干扰；
- 每个像素的线性功率；
- SINR 到速率的映射。

### 完整 3D radio map

- 3D 场景网格；
- 测量面 mesh；
- 3D 射线求交；
- 反射/透射/绕射/散射组合；
- GPU 或 Worker 加速；
- 与当前 2D 编辑器的数据模型整合。

## 7. 当前不应被误解为

- 不是完整 3D 射线追踪；
- 不是 Sionna 等价模型；
- 不是测量级校准模型；
- 不是 MIMO/OFDM 信道模型；
- 不是逐点 SINR 规划器。

当前模型适合：

- 室内 Wi-Fi 覆盖趋势；
- AP 位置和数量对比；
- 墙体/楼板的相对影响；
- 反射、绕射、散射的工程近似。

当前模型不适合：

- 精确路径损耗验收；
- 交叉极化/MIMO 评估；
- 严格 CIR/延迟扩展；
- 需要 3D 家具、天花板、复杂 mesh 的场景。
