# 反射与绕射路径模型改进

本文记录热力图二级路径——反射和绕射——的现状、参考实现与改造范围。参考实现为
`D:\Project\sionna-rt` 的 Sionna RT。

## 现状

热力图每个纹素的计算顺序：

1. 自由空间直射，含三维距离和天线方向图；
2. 单次镜面反射，按功率相加；
3. 单刃峰绕射，按功率相加；
4. 3×3 平滑后量化成色带。

### 反射

- 见 `src/lib/rf/reflection.ts`。
- 镜像法求反射点；
- 检查 AP 与客户端是否在墙面同侧、反射点是否落在线段内；
- 反射系数来自 ITU-R P.2040 平板模型；
- 路径损耗使用 AP → 反射点 → 客户端的实际长度；
- **没有检查两段路径穿过的其他墙**，也没有扣这些墙的损耗。

### 绕射

- 见 `src/lib/rf/diffraction.ts`。
- 所有墙体端点作为刃峰；
- ITU-R P.526 单刃峰公式；
- 只有直连路径墙体损耗超过 3 dB 时才逐渐计入；
- **路径损耗仍使用 AP → 客户端的直线距离**；
- **天线方向仍按 AP → 客户端计算**，不是 AP → 刃峰。

### 已修复

衍射的距离和净空上限曾以世界坐标直接与“米”比较。按标定后的世界单位换算后，
原先 60 m 的上限实际只有约 1.5 m，导致绕射几乎不执行。现在由调用方传入
`metersPerWorldUnit`。

## Sionna RT 的做法

### 反射

`image_method.py` 用镜像法生成镜面反射链，并反向追踪验证：

- 反射点必须在可见表面上；
- 路径中途撞到其他几何体就丢弃；
- 路径长度是实际分段长度之和。

### 绕射

`field_calculator.py` 使用：

- `s'`：AP 到绕射点；
- `s`：绕射点到客户端；
- 扩散因子 `1 / sqrt(s·s'·(s+s'))`；
- 路径损耗和相位都按实际折线路径计算。

### 材料与 SINR

- `radio_materials/itu.py` 使用 ITU-R P.2040 的介电常数和电导率；
- `radio_map.py` 用 `|h|²` 求和得到 path gain，再计算 RSS 和 SINR；
- SINR 包含热噪声和其他 AP 的干扰。

## 本项目采用的模型

Aetherax 是 2D 掩码 + 矢量墙的实时热力图，不引入完整 3D 射线追踪。采用
“2.5D 候选路径”：

- 墙体是竖直面，AP/客户端高度决定三维距离；
- 反射只算一次镜面反射；
- 绕射只算墙端点的单刃峰；
- 各路径功率相加，不使用复数场相干叠加；
- 路径可见性用矢量墙的线段求交判断。

## 改造内容

### 1. 绕射折线路径

`bestDiffraction` 现在返回刃峰点和所属墙索引；热力图用返回的刃峰点计算折线路径：

```text
d1 = |AP − 刃峰|
d2 = |刃峰 − 客户端|
路径损耗 = 自由空间(d1 + d2)
天线损耗 = 按 AP → 刃峰 的方向计算
```

AP → 刃峰、刃峰 → 客户端任一段被其他墙挡住，该刃峰不可用。热力图会从 AP 侧
可见的候选刃峰中，选出一条客户端侧也可见、且刃峰损耗最小的路径；不再因为“最强
刃峰被挡”就整个像素放弃绕射。

候选按 AP 每帧预计算一次：

- `reflectionCandidates` 排除反射系数为 0 的墙；
- `diffractionCandidatesForAp` 排除 AP 侧被挡或超过距离上限的刃峰；
- 纹素循环只遍历这些候选，不再对每个像素重扫全部墙体。

候选本身只取决于 AP 位置/频段、墙体几何和楼层标定，热力图层会跨帧缓存它们；平移、
缩放和平滑参数变化时不需要重建。候选墙较多时，再按墙中点建立均匀网格，纹素循环只
取 AP–纹素中点反射半径内的墙。

### 2. 反射两段墙损

对每条反射：

```text
AP → 反射点 的墙损
+ 反射点 → 客户端 的墙损
```

反射面本身不重复计墙损，由反射系数表示。路径穿墙时保留反射，但扣除墙损；
如果损耗大到低于门限，自然不会着色。

### 3. 可见性与精确性

- 使用 `rayWallLossDb` 对两段路径求墙损和交点；
- 反射面按索引排除；
- 绕射刃峰所属墙按索引排除；
- 路径长度、天线方向均按实际折线计算。

### 4. 单次漫散射

参考 Sionna RT 的 Lambertian 模式，增加一次漫散射：

```text
f_s(θ_s) = cos θ_s / π
墙面散射功率 ∝ S · cos θ_i · f_s(θ_s)
```

- `S` 是材质的 `scatteringCoefficient`，默认 0.15；
- 零衰减的 Virtual Partition 散射系数为 0；
- 用镜面反射点作为整面墙的代表点，不额外做墙面方向采样；
- 与镜面反射共用 AP → 墙 → 客户端的路径长度、天线方向和墙损；
- 作为独立功率项与直射、镜面反射、绕射相加。

这是实时热力图的近似，不是 Sionna 那种对墙面做 Monte Carlo 积分。

### 5. 暂不引入

- 多次反射；
- 复数场相干叠加；
- 完整 3D 楔形绕射；
- 逐点 SINR。

这些是后续独立工作。

## 验收

新增固定场景测试：

1. 同一房间内，直射 RSSI 高于反射/绕射；
2. 在 AP 与客户端之间加一面高损耗墙后，墙后 RSSI 下降；
3. 反射两段路径穿过额外墙时，反射贡献下降；
4. 绕射路径长度使用 `d1 + d2`，不是直线距离；
5. 墙端点被其他墙挡住时，该绕射路径不参与。

现有测试、e2e、桌面构建和 `verify:desktop` 必须保持通过。
