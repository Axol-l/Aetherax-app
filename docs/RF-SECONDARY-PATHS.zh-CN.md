# 无线路径物理模型：现状与未实现项

本文不是变更日志，而是 Aetherax 当前无线传播模型的边界清单：哪些已经做了、哪些还是
近似、哪些完全没有做。实现参考 `D:\Project\sionna-rt` 的 Sionna RT，但 Aetherax 是
二维平面上的实时热力图，不会直接移植 Mitsuba 3D 射线追踪。

## 1. 当前已经实现的链路

热力图对每个纹素按以下顺序计算：

1. 自由空间直射；
2. 单次镜面反射；
3. 单刃峰绕射；
4. 单次漫散射；
5. 各路径按功率相加；
6. 3×3 平滑后量化成色带。

### 1.1 直射

- 路径长度使用三维距离：水平距离 + AP/客户端高差；
- 路径损耗使用工程选择的 log-distance 模型：
  - `lineOfSight`
  - `office`
  - `closedPlan`
- 墙体损耗来自墙体掩码或矢量墙；
- 柱子按真实矩形/圆形几何求射线弦长与入射角，用该材质的 P.2040 透射按弦长缩放后再计入；墙体直接路径仍是栅格掩码的材质标量穿越；
- 楼板损耗来自楼层材质和厚度；
- 客户端高度默认 1.5 m，可由工程设置修改；
- AP 安装高度、天花板高度和抬高面参与垂直距离。

### 1.2 反射

当前是**单次和二次镜面反射**：

- 镜像法求反射点；
- 二次反射先从 AP 对第一面墙镜像，再对第二面墙镜像，反推两个反射点；
- 二次反射候选墙对按正入射功率比预筛，每 AP 最多 8 对，避免逐像素 O(W²)；
- 只接受落在墙段内、AP 与客户端在墙同侧的反射；
- 反射系数来自 ITU-R P.2040 平板模型；
- **只使用反射系数的幅度平方**；P.2040 的复数相位在功率合成阶段被丢弃（见 3.9）；
- 路径长度是 AP → 反射点 → 客户端的实际长度；
- 两段/三段路径分别计算穿墙损耗；
- 反射面自身的墙损被排除，避免和反射系数重复；
- 反射点、路径长度、方向图都按实际几何计算。

### 1.3 绕射

当前是**带高度的竖直刃边绕射**：

- 每面墙的两个端点是从地面到墙顶的竖直刃边；
- ITU-R P.526 单刃峰公式；
- 沿刃边用最小路程求三维绕射点，AP/客户端高度不同时也能落到墙高范围内；
- AP → 刃峰、刃峰 → 客户端都检查可见性；
- 路径损耗使用 `d1 + d2` 的实际三维折线长度；
- 天线方向按 AP → 绕射点计算；
- 从 AP 侧可见、客户端侧也可见的候选刃峰中，取损耗最小的 **最多 4 条**，按功率相加；
- 直连路径墙体损耗超过 3 dB 后才逐渐计入；过渡函数是
  `gate = clamp((wallLoss - 3) / 6, 0, 1)`，即 3 dB 处为 0、9 dB 处为 1，中间线性。
  3 dB 和 9 dB 是经验值，不是 ITU-R P.526 的理论阈值；它们的目的是避免阴影边界出现硬缺口。

### 1.4 漫散射

当前是**一维墙面积分**：

- 每面墙按长度切段，面元长度随频段和 AP 到墙的距离缩放：高频更细、近场更细；
- 每个面元面积按 `段长 × 楼层净高` 计算；
- AP 一侧不可见的面元不生成，客户端一侧不可见的面元逐纹素跳过；
- 使用 Sionna `DirectivePattern` 风格的方向图（`alpha = 4`），散射能量集中在镜面反射方向；
- 方向图按入射角归一化；
- 面元贡献按 `S · cos θ_i · f_s · A` 计；
- 各面元功率不相干相加；
- 材质 S 内置值来自 Remcom 5G mmWave office 示例的工程近似。

| 材质 | 2.4 GHz | 5 GHz | 6 GHz | 备注 |
|---|---:|---:|---:|---|
| Drywall | 0.05 | 0.10 | 0.12 | 60 GHz 示例为 0.2，按频段下调 |
| Concrete | 0.15 | 0.25 | 0.30 | 60 GHz 示例为 0.4 |
| Metal | 0.10 | 0.15 | 0.18 | 60 GHz 示例为 0.2 |
| Wood | 0.05 | 0.10 | 0.12 | 无实测值 |
| Glass | 0.02 | 0.03 | 0.04 | 无实测值 |
| Brick | 0.08 | 0.12 | 0.15 | 无实测值 |
| Door | 0.05 | 0.10 | 0.12 | 无实测值 |
| Virtual Partition | 0 | 0 | 0 | 零衰减隔断 |

这些是**工程预设**，不是测量得到的材料常数。Remcom 的 60 GHz 示例范围是 0.1–0.5；
当前表把 60 GHz 值按频段下调，避免直接把毫米波 S 套到 2.4/5/6 GHz。没有实测数据的
材质只用于给出数量级，不能当作验收依据。自定义材质显式填写
`scatteringCoefficient` 时，优先使用该值，不再套用频段预设。

### 1.5 天线

- 垂直切面用 `beamwidthDeg + aimDeg` 近似；
- 水平切面用 `horizontalBeamwidthDeg + facingDeg` 近似；360° 为全向，180°–359° 仍是有限宽度面板；
- 吸顶 AP 默认 `horizontalBeamwidthDeg = 360°`、`aim = 30°`；
- AP 有 0–90° 线极化角，接收端固定按垂直极化投影取功率（不再作为工程设置暴露）；
- 没有导入厂商实测三维方向图。

### 1.6 功率合成

- 每条路径保留复振幅和相位；
- 同一 AP 的路径先按 V/H 复场相加，再取功率；
- AP 之间仍按功率非相干相加；
- 反射使用 P.2040 的 TE/TM 复反射系数；
- 直射、绕射、散射按 AP 发射极化角投影到 V/H；
- 热力图可切换 RSSI / SINR / Rate。

### 1.7 SINR

SINR 视图按每个纹素计算：

```text
signal      = 最强 AP 的复场功率
interference = Σ 其他 AP 的功率 × 信道干扰权重
noise       = thermalNoiseFloorDbm(服务 AP 的信道宽度)
SINR        = 10 log10(signal / (noise + interference))
```

信道权重第一版：

- 同中心或包含关系：`min(1, O / W_server)`，不再乘 ACIR；
- 部分重叠的邻道：`min(1, O / W_server) × 10^(-ACIR/10)`；
- 不重叠但边缘间隔 ≤ 5 MHz：`10^(-ACIR/10)`；
- 不同频段或更远：0；
- 缺少信道号：按同频处理。

默认 `ACIR = 25 dB`。5 GHz 的 40/80/160 MHz 使用实际分组中心，而不是主信道中心；第一版不做逐厂商频谱掩模，但邻频权重已用于优化器的干扰评分和信道分配。

色阶固定为 -5..30 dB。Rate 视图把该 SINR 按 802.11ax 20 MHz、2 流近似映射到 MCS 和 PHY rate。

### 1.8 二维墙面积分

漫散射默认是一维墙段积分。当楼层净高超过 **4 m** 时，在高度方向增加 2 或 3 层
面元，形成条件触发的二维墙面积分；每个面元带三维位置、面积和复相位。

### 1.9 缓存与候选

- 反射/绕射/散射候选按 AP 预计算；
- 候选跨帧缓存；
- 反射候选墙多时按墙中点建均匀网格；
- 热力图按完整输入键做多楼层缓存；
- 绕射和反射的候选不是严格的三维射线追踪，只是二维几何候选。

## 2. 当前模型的整体边界

Aetherax 目前是：

```text
2D 平面掩码
+ 竖直墙体
+ 固定客户端高度
+ 2.5D 距离和高度差
```

不是：

```text
完整 3D 场景
+ 任意测量面
+ 多次散射
+ 复数场
```

## 3. 未实现或仍为近似的物理模型

### 3.1 三维几何与任意 radio map 面

**状态：未实现。**

当前没有：

- 墙体厚度方向上的真实三维几何；
- 墙高、窗台、门洞的完整三维形状；
- 地板、天花板作为可反射/透射的面；
- 家具、隔断、柱子的完整三维网格；
- 任意 mesh 作为 radio map 测量面；
- 3D 射线与场景求交。

Sionna 的 `RadioMapSolver` 可以把任意 mesh 当作测量面，每个三角形是一个 cell。
要做到这一点，仅“墙端点带高度”不够，还需要整个 3D 场景和 3D 路径求交。

### 3.2 多次反射

**状态：部分实现。**

当前支持单次和二次镜面反射（二次反射只用于热力图，实时覆盖率尚未累加）。
还没有：

- 二次、三次反射；
- 多次反射路径的可见性；
- 多次反射的路径损耗累积；
- 多次反射的功率合成；
- 反射路径之间的相位关系。

在走廊、房间角落和金属表面附近，多次反射会明显影响阴影区和延迟扩展。

### 3.3 粗糙表面与 Angle-dependent 反射

**状态：部分近似。**

当前：

- 反射系数按 P.2040 平板模型计算；
- 只和材质、频段、入射角有关；
- 不建模表面粗糙度引起的漫反射比例；
- 不建模反射相位的随机化；
- 不建模交叉极化。

真实粗糙表面的镜面反射会随频率、粗糙度、入射角变化，并伴随漫散射。Sionna 用
有效粗糙度模型和散射系数描述这部分。

### 3.4 透射与折射

**状态：部分实现。**

当前：

- 矢量墙的反射/散射路径已按入射角调用 P.2040 slab 透射损耗；
- 面元路径与反射路径的穿墙损耗是角度相关的；
- 直接路径的栅格墙损仍使用标量 dB 表，尚未逐墙按入射角计算；
- 不计算折射角；
- 不处理门窗洞口的几何绕射/透射组合。

Sionna 的 `RadioMaterial` 用 P.2040 的介电常数和电导率计算 slab 的反射/透射系数，
并考虑厚度和入射角。

### 3.5 三维楔形绕射

**状态：部分实现。**

当前已经把墙端点升级为从地面到墙顶的竖直刃边，并用最小路程求三维绕射点。
仍没有：

- 楔形两个面的夹角；
- 三维 Keller 锥的严格解；
- Fresnel 过渡区和阴影边界；
- 极化相关的绕射系数；
- 二次绕射。

因此：

- 上层/下层路径的绕射角只是近似；
- 斜向绕射的路径长度不是严格三维；
- 靠近墙端、墙角、窗边时误差会变大。

### 3.6 绕射的高阶路径

**状态：部分实现。**

当前会累加最多 4 条可见刃峰的绕射功率，不再只取一条。仍没有：

- 绕射后再反射；
- 反射后再绕射；
- 多次绕射；
- 绕射路径穿过其他墙后的衰减。

Sionna 的路径求解器可以组合 reflection / diffraction / diffuse 交互；Aetherax 目前
是“每种二级路径单独算”。

### 3.7 完整的漫散射模型

**状态：部分实现。**

当前：

- 使用 Directive（`alpha = 4`）；
- 一维墙段积分，楼层层高超过 4 m 时条件触发高度方向采样；
- 每个面元一个确定点；
- 面元已进入复场求和，保留路径相位；
- 漫散射支持固定交叉极化比例（默认 0.2）；
- 没有 backscattering；
- S 有 2.4/5/6 GHz 的工程预设，但没有按粗糙度、含水率、入射角校准；
- 墙高使用楼层净高，未区分实际墙高。

Remcom 的示例使用的也是 **Directive** 模型；其参数还包括：

- 散射因子 S；
- 交叉极化比例；
- Alpha（前向波束宽度）；
- 可选 backscatter。

Sionna 的 `scattering_pattern.py` 提供 Lambertian、Directive 和 Backscattering 三种模式，
并做归一化。Aetherax 目前实现了 Directive 的一维近似版本，没有 backscattering 和交叉极化。

### 3.8 极化

**状态：部分实现。**

当前：

- 支持 AP 发射极化角 0–90°；
- 接收端固定按垂直极化收（工程里不再有这个设置项），接收功率是复场在垂直方向上的投影；
- 直射、绕射、散射投影到 V/H；
- 反射使用 P.2040 的 TE/TM 复系数，并封装为 2×2 Jones 矩阵；
- 漫散射支持固定交叉极化比例，并用旋转 Jones 矩阵转到正交极化；
- 热力图按 V/H 复场合成。

仍没有：

- 任意粗糙表面的非对角反射 Jones 项；
- 极化相关的绕射系数；
- MIMO 极化矩阵。

RSSI 规划可以暂时忽略极化，但这会使：

- 交叉极化链路预测偏差很大；
- 金属、玻璃、粗糙表面的散射量级偏差；
- MIMO 流数和相关矩阵无法评估。

### 3.9 复数场与相位

**状态：已实现基础复场，未实现完整信道。**

当前：

- 路径保留复振幅和 `-kd` 相位；
- 同一 AP 的路径按 V/H 复场相加；
- 反射系数保留相位；
- 支持多径相消/相长。

仍没有：

- 频率选择性衰落；
- 延迟扩展；
- 相干带宽；
- MIMO 信道矩阵；
- 完整 2×2 Jones 极化矩阵。

### 3.10 噪声、干扰与 SINR

**状态：已实现基础逐点 SINR、估算 PHY 速率视图和粗粒度业务容量。**

当前：

- 热力图可切换 RSSI / SINR / 估算 PHY 速率；
- SINR 使用最强 AP 信号、按信道关系加权的其他 AP 功率和最强 AP 信道宽度对应的热噪声；
- 同频按 1、邻频按重叠比例 × 25 dB ACIR、紧邻不重叠按 25 dB 泄漏、异频为 0；
- 5 GHz 40/80/160 MHz 使用分组中心频率；
- SINR 色阶固定为 -5..30 dB，速率色阶按服务 AP 的信道带宽自动缩放；
- 使用 802.11ax、GI=800 ns、MCS 0–11 的静态 PHY 表，覆盖 20/40/80/160 MHz 和 1/2 空间流；第一版界面固定按 2 流估算；
- MCS 门限是 2–35 dB 的 SNR 门限，不是接收灵敏度 dBm；
- 邻频权重已进入优化器信道分配/干扰评分；
- 已提供粗粒度业务容量：1/2 流终端构成、按房间类型的 2/10/20 Mbps/终端需求、中位 SINR 供给和 5% 分位边缘警告；未标注房间类型的面积不计业务需求。

仍没有：

- 逐厂商的频谱掩模/ACLR 校准和 OBSS 区分；
- 帧聚合、重传和空口竞争导致的吞吐折算；
- 逐终端/逐房间的详细业务调度。

PHY 参考速率乘 MAC 折损得到“预估吞吐”。当前默认 MAC 效率 45%，只代表帧聚合充分、低碰撞时的理想上限，不是实测吞吐；1 流终端约为 2 流的一半。

Sionna 的 radio map 直接使用：

```text
SINR = RSS / (N0 + Σ 其他 AP 的 RSS)
```

Aetherax 在此基础上增加了按信道重叠/ACIR 的干扰权重，但仍不是逐厂商射频前端模型。容量模型仍是独立的客户端数估算。

### 3.11 天线与阵列

**状态：简化。**

没有：

- 厂商实测三维方向图；
- 天线方向图的频率相关数据；
- 阵列流形和相位；
- 波束赋形；
- 接收天线方向图；
- 天线效率、损耗、端口方向图；
- 天线倾角的机械/电子区分。

当前 `beamwidthDeg + horizontalBeamwidthDeg + aimDeg + facingDeg` 只是垂直/水平切面的解析近似。

- 垂直切面由 `beamwidthDeg` 和 `aimDeg` 描述，180° 表示平坦垂直方向图；
- 水平切面由 `horizontalBeamwidthDeg` 和 `facingDeg` 描述，360° 表示全向；
- 180° 到 359° 仍是有限宽度的水平面板，不会退化成全向；
- 水平切面包含前后比，背面按 `frontToBackDb` 衰减；
- 天线参数会同时进入热力图、覆盖率和优化器 worker。

## 4. 未实现项的优先级

排序按“对当前室内规划结论的影响”而不是按实现难度。已经完成的逐点 SINR、二维墙面积分和基础复场/极化不再列入待办。

### P0：影响当前室内覆盖率/容量结论可信度

1. **直射路径的墙体斜入射与厚度透射**
   - 柱子的直射路径已按实际弦长和入射角计算，并替换栅格的一次材质损耗；
   - 墙体直接路径仍是材质标量，按 `typicalThickness` 计一次；不随入射角、实际墙厚变化；
   - 结果是 AP 靠近厚墙或金属墙时，覆盖率和热力图的衰减可能偏离实际；
   - 需要先让直接路径和反射/散射共用角度相关的 P.2040 透射，再决定墙/厚墙是否按真实路径长度缩放。

2. **邻频干扰的完整频谱模型**
   - 第一版已按信道范围重叠、25 dB ACIR 和 5 MHz 紧邻阈值计算 SINR 权重；
   - 仍是矩形频谱，没有逐厂商 ACLR、频谱掩模、OBSS/同 BSS 区分；
   - 1/6 与 36/40 目前都取同一个最低泄漏权重，没有按间隔继续衰减；
   - 邻频权重已进入优化器的信道分配和干扰评分；
   - 绝对值需要实测或厂商数据校准。

3. **Rate → 吞吐/楼层容量**
   - SINR→MCS→PHY rate 已完成，Rate 视图可用于相对比较；
   - 还没有逐终端业务量、帧聚合、空口竞争、协议开销和终端能力；
   - 因此容量条仍是独立的客户端数估算，不能把 Rate 视图直接当作可售吞吐。

### P1：影响复杂户型和多 AP 规划

4. **三维楔形绕射与高阶绕射**
   - 已实现竖直刃边、三维最小路程和多刃峰功率相加；
   - 仍缺楔形夹角、严格 Keller 锥、Fresnel 过渡区、极化绕射系数和二次绕射。

5. **二次反射进入覆盖率/优化器**
   - 热力图已有最多 8 个候选墙对的二次反射；
   - 实时覆盖率已加入二次反射；
   - 优化器最终精确评分已包含二次反射，PSO 搜索阶段仍只按单次反射/主路径近似以控制耗时；
   - 复杂走廊和金属房间中，这仍可能影响搜索过程选中的位置。

6. **天线与终端能力**
   - 水平/垂直切面已有解析近似；
   - 仍缺厂商实测三维方向图、频率相关方向图、MIMO 空间流数和终端接收方向图；
   - Rate 目前固定按 2 条空间流估算。

### P2：完整射线追踪能力

7. **完整 3D 场景 / 任意 radio map 面**
   - 地板、天花板、家具、mesh 测量面；
   - 3D 求交和 3D 路径。

8. **完整信道与移动性**
   - 频率选择性衰落、延迟扩展、相干带宽；
   - MIMO 信道矩阵和完整 2×2 Jones 极化；
   - 移动客户端、多普勒和动态遮挡。

## 5. 做这些事需要的前提

### 角度与厚度透射

- 直接路径经过的墙体/柱子实际厚度；
- 入射角与墙体法线；
- P.2040 材质参数；
- 柱子的实际截面和路径长度；
- 与现有栅格墙损表的兼容/回退。

### 邻频干扰

- 每个 AP 的信道和带宽（已有）；
- 5 GHz 40/80/160 MHz 分组中心表（已有第一版）；
- 逐厂商 ACLR/频谱掩模；
- OBSS/同 BSS 与 CCA 门限；
- 每个像素的干扰功率分解（已有第一版）；
- 优化器信道分配/干扰评分已接入；
- 实测校准数据。

### Rate → 吞吐

- 终端能力（空间流、MCS、带宽）；
- 业务量和并发终端数；
- 帧聚合、协议开销、重传；
- 空口竞争/CCA 占用；
- 从逐点 PHY rate 到楼层容量的聚合规则。

### 三维楔形绕射

- 墙高、墙厚；
- 墙端点的三维坐标；
- AP/客户端三维坐标；
- 刃边与射线的三维求交；
- 楔形两面夹角；
- 可见性；
- Fresnel/UTD 系数；
- 性能预算。

### 多次反射

- 候选路径枚举；
- 每次反射的可见性；
- 路径长度和墙损累积；
- 组合爆炸控制；
- 缓存/剪枝。

### 完整 3D radio map

- 3D 场景网格；
- 测量面 mesh；
- 3D 射线求交；
- 反射/透射/绕射/散射组合；
- GPU 或 Worker 加速；
- 与当前 2D 编辑器的数据模型整合。

## 7. 当前不应被误解为

- 不是完整 3D 射线追踪；
- 不是 Sionna 等价模型；
- 不是测量级校准模型；
- 不是 MIMO/OFDM 信道模型；
- 不是逐点 SINR 规划器。

当前模型适合：

- 室内 Wi-Fi 覆盖趋势；
- AP 位置和数量对比；
- 墙体/楼板的相对影响；
- 反射、绕射、散射的工程近似。

当前模型不适合：

- 精确路径损耗验收；
- 交叉极化/MIMO 评估；
- 严格 CIR/延迟扩展；
- 需要 3D 家具、天花板、复杂 mesh 的场景。
