## 1. 启动与界面

### 1.1 启动

1. 运行安装包 Aetherax_0.1.0_x64-setup.exe，按向导完成安装。
2. 从开始菜单或安装目录运行 Aetherax。
3. 首次启动会显示欢迎窗口。点击 Get Started 进入主界面；勾选 Don't show this again 后不再显示。
4. 如果窗口空白，安装 Microsoft Edge WebView2 Runtime 后重新启动。

### 1.2 主界面

界面分为五个区域：

1. 顶部工具栏：工程名、File 菜单、撤销、重做、单位切换、语言切换、帮助、侧栏开关。
2. 左侧侧栏：Floorplan 与 APs 两个标签页，底部固定 Coverage、Placement optimiser 和 Placement advice。
3. 中间画布：平面图、墙体、AP、热力图和各类覆盖物。
4. 画布左下角 Layers 面板：图层开关、底图不透明度、视图角度、信号强度色标。
5. 底部状态栏：缩放比例、Fit 按钮、单层/平铺/堆叠/3D 视图切换。

顶部工具栏的工程名可以双击改名，输入后按 Enter 确认，按 Esc 取消。帮助按钮打开版本信息、快捷键和入门说明。

## 2. 工程与文件

### 2.1 新建工程

1. 点击 File。
2. 点击 New Project。
3. 输入工程名称。
4. 点击 Create。

新建会清空当前布局，恢复为单层、5 GHz、20 MHz、FCC 的空白工程。需要保留当前内容时，先导出工程文件。

### 2.2 打开工程

1. 点击 File。
2. 点击 Open Project...。
3. 选择 .json 工程文件。
4. 打开后当前工程被替换。

可以打开本程序导出的工程文件。其他来源的 JSON 必须符合本程序的工程结构，否则会提示导入失败。

### 2.3 保存工程

1. 按 Ctrl+S。
2. 界面显示 Saved 即完成。

保存写入程序自己的本地存储，不会生成文件。日常编辑会自动保存，Ctrl+S 用于立即落盘。File 菜单没有单独的保存项。

### 2.4 导出工程文件

1. 点击 File。
2. 点击 Export Project File...。
3. 浏览器或桌面窗口会下载一个 .json 文件。
4. 把该文件保存到固定位置，作为备份或迁移用。

工程文件包含所有楼层、平面图图像、墙体、规划范围、AP、抬升面、标注和覆盖率数据。换电脑时用 Open Project... 导入这个文件。

### 2.5 导出 PNG

1. 调整好当前视图和楼层。
2. 点击 File，选择 Export as PNG。
3. 程序按当前画布导出 2 倍分辨率 PNG。
4. 在下载目录查看文件。

PNG 只包含当前画布视图，不包含侧栏和被隐藏的图层。

### 2.6 导出 PDF

1. 点击 File，选择 Export as PDF。
2. 程序会依次切换楼层并截取画布，生成横向 A4 报告。
3. 等待下载完成，导出期间不要操作画布或切换楼层。
4. 报告包含封面、每层平面图截图、AP 清单和覆盖率数据。

导出过程中界面可能短暂切换楼层，这是报告截图的正常过程。

## 3. 楼层管理

### 3.1 添加楼层

1. 打开 Floorplan 标签页。
2. 在楼层条右侧点击 +。
3. 新楼层以 Floor N 命名并自动切换过去。

新楼层会继承当前楼层的比例标定，但不会复制平面图、墙体、AP 或规划范围。需要单独导入平面图并绘制或识别墙体。

已有楼层的布局可以复制：打开该层 Floorplan 卡片，点击 Copy layout…，选择目标楼层或 New floor，再勾选平面图与比例、墙体/柱子/房间、规划范围、抬升面和标注。AP 永远不会被复制。

### 3.2 切换楼层

1. 点击楼层条上的楼层名称。
2. 画布切换到该层。

每层的平面图、墙体、标定、规划范围、AP、抬升面和标注相互独立。

### 3.3 重命名楼层

1. 双击楼层名称。
2. 输入新名称。
3. 按 Enter 确认，按 Esc 取消。

### 3.4 调整楼层顺序

1. 选中要移动的楼层。
2. 点击楼层名称左侧的 ◀ 或右侧的 ▶。

顺序决定楼层标高和堆叠视图中的上下关系。

### 3.5 删除楼层

1. 选中要删除的楼层。
2. 点击楼层名称右侧的 ×。
3. 在确认框中确认删除。

删除会同时删除该层的 AP 和平面图存储。最后一层不能删除。

## 4. 导入平面图

### 4.1 支持的格式

支持 PNG、JPEG、SVG。不支持 PDF。PDF 图纸先导出为 PNG，再导入。

### 4.2 导入方法

方法一：

1. 打开 Floorplan 标签页。
2. 点击 Import Floorplan。
3. 选择图片文件。

导入新平面图会清除当前楼层的比例标定，导入后需要重新标定。底图透明度可以用 Floorplan 卡片的 Opacity 或 Layers 面板的 Plan opacity 调整。

方法二：

1. 把 PNG、JPEG 或 SVG 文件直接拖到画布上。
2. 松开鼠标后开始导入。

### 4.3 使用示例图

1. 在导入区域点击 Apartment、House 或 Office 示例。
2. 程序载入内置示例平面图，用于熟悉流程。

### 4.4 从零绘制

1. 点击 Draw from Scratch。
2. 不导入底图，直接使用 Draw wall 和 Place APs 建立平面。

适合没有现成图纸、只需要布置 AP 的场景。

### 4.5 识别墙体

导入 SVG 后，程序优先按矢量对象识别墙、窗、门：

1. 导入后侧栏出现 Read from vector geometry 区块。
2. 区块标题显示墙、窗、门的数量。
3. 展开区块可以逐项修改元素类型：Wall、Door、Window、Not a barrier。
4. 修改后立即重新生成墙体掩膜。
5. 点击 Read walls from pixels instead 可改用像素识别。
6. 点击 Reset 撤销手动分类。

导入 PNG 或 JPEG 时按像素识别，不会出现矢量分类列表。

已有平面图时，可以在 Floorplan 标签页的 Walls 卡片中点击 Detect walls 或 Re-detect walls 重新识别。重新识别会清除手工绘制的墙体和已上色的材质，执行前会要求确认。

### 4.6 移除平面图

1. 点击平面图卡片底部的垃圾桶按钮（Remove floorplan）。
2. 确认提示。

该操作会删除当前楼层的平面图、墙体与柱子、规划范围、抬升面、标注、墙体掩膜、比例标定、房间类型与密度覆盖、房间标签以及该层所有 AP。只删除底图而保留 AP 时，不要使用这个按钮。

## 5. 比例标定

比例按楼层独立保存。新楼层继承当前楼层的比例，之后可以单独重新标定。

### 5.1 用已知距离标定

1. 打开 Floorplan 标签页。
2. 找到 Scale 卡片，点击 Measure a distance。
3. 在平面图上点击已知线段的一个端点。
4. 点击另一个端点。
5. 在输入框中填入这段线的真实长度。
6. 确认单位。工具栏的 m/ft 开关决定输入单位。
7. 点击 Apply。

标定完成后，Scale 卡片显示当前比例，画布上的距离、AP 半径和面积按真实单位计算。

### 5.2 重新标定

1. 点击 Recalibrate。
2. 重复 5.1 的步骤。

重新标定只影响当前楼层。

### 5.3 未标定的影响

未标定时，比例显示 Not set，所有距离和 AP 半径按世界单位计算，覆盖率和优化结果不能当作真实物理结果使用。先完成标定，再评估覆盖率。

## 6. 楼层属性与对齐

### 6.1 楼层属性

在 Floorplan 标签页展开 Floor properties：

1. Ceiling height：层高，单位跟随 m/ft 开关。
2. Floor thickness：楼板厚度。
3. Floor material：楼板材质，影响跨层损耗。

这些值用于 3D 视图、跨层路径和 AP 高度。

### 6.2 对齐楼层

1. 展开 Floor properties。
2. 修改 Align X 或 Align Y，按真实距离平移当前楼层。
3. 或者点击 Drag to align 进入拖动对齐模式。进入后 Floor below 图层自动打开。
4. 在画布上按住左键拖动，把当前楼层对到下一层上。
5. 再次点击按钮或按 Esc 结束。

对齐会同时移动该层的平面图、墙体、规划范围和 AP。

## 7. 墙体

### 7.1 绘制墙体

1. 打开 Floorplan 标签页。
2. 在 Walls 卡片点击 Draw wall。
3. 画布顶部出现墙体工具栏。
4. 选择 Walls 或 Columns。
5. 绘制柱子时选择 Rectangle 或 Circle。
6. 点击 Material 选择下一段墙的材质。
7. 在画布上点击墙体起点。
8. 点击终点完成这一段。
9. 按住 Shift 画正交墙。
10. 按 Esc 退出墙体工具或取消未完成的墙段。
11. 点击 Done 退出墙体工具。

绘制时端点会吸附到已有墙体。墙体掩膜、室内范围和覆盖率都由这些墙线推导。

### 7.2 修改墙体材质

1. 点击一段墙体将其选中。
2. 右键点击该墙体。
3. 在材质列表中选择材质。

材质列表底部可以添加自定义材质：

1. 点击 + Custom material。
2. 输入 Name。
3. 输入 Loss per crossing。
4. 输入 Thickness。
5. 点击 Add。

自定义材质可以删除，删除后使用该材质的墙体按默认墙体计算。

### 7.3 删除墙体

1. 点击墙体选中。
2. 按 Delete 或 Backspace。
3. 柱子同样先选中再删除。

删除最后一根墙或柱子时，墙体掩膜会同步清空。

### 7.4 擦除与清空

1. 在 Walls 卡片点击 Draw wall 进入墙体工具。
2. 选择 Erase。
3. 在墙上拖动擦除。
4. 点击工具栏右侧的垃圾桶图标清空当前楼层所有墙体和柱子。

清空墙体不会删除 AP，但覆盖率会按空墙体重算。

### 7.5 识别墙体

1. 在 Walls 卡片点击 Detect walls。
2. 已有掩膜时按钮显示 Re-detect walls。
3. 重新识别会替换墙体并清除手工上色，执行前确认。

## 8. 规划范围

规划范围用于明确本层哪些区域算作楼层。未绘制时使用自动识别的范围。

### 8.1 绘制规划范围

1. 打开 Floorplan 标签页。
2. 在 Planning area 卡片点击 Draw planning area。
3. 在画布上依次点击角点。至少需要三个角点。
4. 角点会吸附到已绘制的墙体。
5. 第三个角点落下后，顶部出现 Confirm area。
6. 点击回第一个角点可以闭合轮廓，轮廓闭合后仍可撤销或取消。
7. 点击 Confirm area 应用范围。
8. 点击 Undo corner 撤销上一个角点，按 Backspace 效果相同。
9. 点击 Cancel 或按 Esc 放弃本次绘制。

### 8.2 重新绘制

1. 点击 Redraw planning area。
2. 重复 8.1。

已应用的范围在绘制期间以虚线显示，确认后隐藏。侧栏按钮文字可以判断当前是否已有规划范围。

### 8.3 规划范围的作用

规划范围是楼层范围的最终依据。它会限制热力图和覆盖率的计算区域，也用于判断 AP 是否在楼层内。

没有绘制规划范围时，使用墙体推导出的自动范围。自动范围在墙洞较大时可能不准确，此时应手工绘制。

## 9. 放置与编辑 AP

### 9.1 放置 AP

1. 切到单层视图。
2. 在左侧 Coverage 区域点击 Place APs。
3. 画布顶部出现 AP 放置工具栏。
4. 选择 Mounting：Ceiling mount、Floor mount 或 Wall mount。
5. 在画布上点击放置。
6. 放置多个 AP 时继续点击。
7. 点击 Done 或按 Esc 退出。

Wall mount 必须点击在距墙 1 米以内。AP 会自动吸附到墙面，并按朝向确定覆盖方向。

### 9.2 AP 列表

1. 打开 APs 标签页。
2. 列表显示当前工程的所有 AP。
3. 点击一个 AP 进入编辑。
4. All 选中全部 AP。
5. Delete selected 删除选中的 AP。
6. Clear 清空工程中所有 AP。

多选时按 Shift 点击 AP，或在空白画布上拖出选择框。拖动 AP 可以移动位置。固定位置在 AP 编辑页的 Pin position 中设置。

### 9.3 编辑 AP

选中 AP 后，Properties 区域可以修改：

1. Model：选择设备型号，自动填入频段、功率、范围和该型号的建议终端数。
2. Name：AP 名称。
3. Band：2.4 GHz、5 GHz 或 6 GHz。
4. Channel Width：信道宽度。
5. Channel：Auto 由求解器分配，选择具体数字则固定该信道。
6. TX Power：发射功率，单位 dBm。
7. Clients：该 AP 计划承载的并发终端数；选择型号时自动填入建议值，也可以单独修改。
8. Mounting：安装方式。
9. 安装高度：Mounting 右侧的数值框。
10. Antenna：Vertical beamwidth、Horizontal beamwidth 和 Aim。Vertical 控制垂直切面；Horizontal 控制平面方向图，360° 为全向，小于 360° 时按面板处理；Aim 是垂直峰值方向，正值向下。新建吊顶 AP 默认 Aim 30°、Horizontal 360°，壁挂 AP 默认 Horizontal 90°。
11. Facing：Wall mount 或 Horizontal 小于 360° 时显示，表示平面内的朝向角。
12. Position：显示当前 X、Y 坐标，不可直接输入；拖动 AP 移动位置。
13. Pin position：固定该 AP 的位置，优化器不会移动它。

修改天线、朝向、安装高度或位置后，热力图和覆盖率都会重算。CO-CHANNEL CONFLICTS 区域列出同信道冲突的 AP。

### 9.4 删除 AP

1. 选中 AP。
2. 按 Delete 或 Backspace。
3. 或在 AP 编辑页点击 Delete Access Point。
4. 多选时点击 Delete All 删除选中的 AP。

### 9.5 AP 在楼层外的警告

Allow APs outside the floor boundary 关闭时，手动点击边界外会拒绝放置并给出提示；落到边界外的 AP 会在画布下方显示警告。打开后，放置和优化都允许 AP 在边界外，警告不再出现。警告可以单独关闭。

## 10. 覆盖率与优化器

### 10.1 查看覆盖率

1. 放置至少一个 AP。
2. Coverage 区域显示当前楼层覆盖率。
3. 多楼层工程显示 Whole building 平均值、最弱楼层和已测量楼层数。
4. 点击 Whole building 标题可以展开计算说明。

覆盖率按密度加权，房间类型和密度会影响结果。它回答的是“多少比例的加权采样点达到覆盖门限”，不是终端容量；覆盖门限默认 −70 dBm，可在优化器设置里修改。

Coverage 下方有一条 Capacity 容量条：显示本层当前 AP 数 / 按房间密度和每台 AP 的 Client 容量估算需要的 AP 数。容量不足时条变红；每台 AP 的 Client 数量可以在 AP 编辑页单独修改，型号会给出一个建议初始值。没有房间类型/密度数据时，容量条隐藏。

### 10.2 优化放置

单层工程：

1. 点击 Optimize placement。
2. 进度条显示优化进度。
3. 优化完成后 AP 移动到新位置。
4. 需要撤销时按 Ctrl+Z。

多楼层工程有两个按钮：

1. Optimize all floors：逐层轮流优化，直到整栋覆盖率不再提升。设了 Min coverage 时，还会对未达标的最弱层单独补跑（最多两轮，只在这层仍在提升时继续）。
2. Optimize this floor：只优化当前楼层，其他楼层不动。

优化过程中可以点击 Cancel 中止。

### 10.3 优化器设置

点击 Placement optimiser 右侧的齿轮：

1. Allow APs outside the floor boundary：允许 AP 落在楼层边界外（有规划范围时以它为准，否则按识别出的建筑内部），默认关闭。
2. Coverage threshold：覆盖率判定门限，默认 -70 dBm；高密度办公区可提高到 -65 或 -60。热力图从门限下方 10 dB 开始着色，边缘仍保留梯度。
3. Interference：同信道干扰在评分中的权重，0 到 1，步长 0.05。
4. Min coverage：最低覆盖率约束，0 表示不约束（此时放置建议不估增删 AP 的数量）。
5. Client height：客户端离地高度。
6. Restarts：优化重启次数，1 到 8。
7. Propagation：传播环境，可选 Walls drawn in full、Walls partly drawn、Walls barely drawn，按墙体绘制完整程度选择。

容量不在这里设置：每台 AP 的 Clients 数量在 AP 编辑页单独修改，未设置时默认为 25。

影响优化评分的设置需要重新运行优化才会生效；Coverage threshold 会立即重算覆盖率，热力图也跟着门限重画。改过评分设置又没重跑时，界面会提示屏幕上的布局是按旧设置选的。

### 10.4 放置建议

Placement advice 区域根据最近一次优化结果给出增删 AP、调整楼层或信道建议。增删 AP 的数量估计以 Min coverage 为目标；没设最低覆盖率时，面板只报容量、信道、干扰这些不依赖目标的问题。容量约束触发时会单独显示“Client capacity”，说明容量覆盖的终端数和建议增加的 AP 数；此时不会仅因为覆盖率高就提示删除 AP。点击 Dismiss 关闭。

### 10.5 信道分配

信道由求解器自动分配。需要固定某个 AP 的信道时，在 AP 编辑页把 Channel 从 Auto 改为具体信道。固定后该 AP 不再参与信道重分配。

## 11. 热力图与图层

### 11.1 显示热力图

1. 放置至少一个 AP。
2. 点击 Layers 面板中的 Signal heatmap，或按 H。
3. 颜色表示接收信号强度，单位 dBm。
4. 低于热力图着色下限（覆盖门限下方 10 dB）的区域保持透明。

Layers 面板中的按钮会显示当前视图，例如 `Heatmap view: RSSI`；点击后循环切换：

1. RSSI：接收信号强度，色标单位 dBm；
2. SINR：最强 AP 与服务小区干扰的比值，色标固定 -5..30 dB；
3. Rate：规划用的估算速率，色标按当前 AP 的信道带宽自动缩放。

SINR 会把同频和邻频 AP 计入干扰，其他频段的 AP 不计入同一次 SINR。Rate 视图是规划用的估算速率，用来比较覆盖质量，不是终端实测吞吐。

### 11.2 图层开关

Layers 面板包含：

1. Signal heatmap：信号热力图。
2. Floorplan：底图。
3. Access points：AP 标记和覆盖半径。
4. Walls：墙体。
5. Room labels：房间标签。
6. Floor below：下一层地图。
7. Labels：AP、墙体和测量标签。
8. Notes：标注。
9. Grid：网格。

Room labels、Floor below、Labels、Notes、Grid 只在单层视图显示。

### 11.3 底图不透明度

1. 在 Layers 面板找到 Plan opacity。
2. 拖动滑块调整底图透明度。
3. 该值同时作用于单层视图和多层卡片。

### 11.4 信号色标

Layers 面板底部显示当前指标的色标。RSSI 色标范围随覆盖门限变化；SINR 固定 -5..30 dB；Rate 按当前信道带宽自动缩放。最左侧的深色格表示低于门限、无可用信号。

## 12. 视图

### 12.1 单层视图

1. 点击状态栏第一个图标进入单层视图。
2. 滚轮缩放，按住鼠标中键拖动平移。
3. 点击 Fit 缩放到可见范围。
4. 只有单层视图可以编辑墙体、AP、规划范围、抬升面和标注。

### 12.2 平铺视图

1. 点击状态栏第二个图标。
2. 每层显示为一张卡片，并排排列。
3. 点击卡片切换到该层。
4. 卡片按各层标定比例绘制，比较的是真实尺寸。
5. 平铺视图只读，不能编辑几何。

### 12.3 堆叠视图

1. 点击状态栏第三个图标。
2. 楼层按层高堆叠。
3. 按住左键拖动旋转视角。
4. Layers 面板出现 Rotate、Tilt、Spacing。
5. 多楼层时可以打开 Only this floor，只显示当前层。
6. 点击某一层切换到该层。
7. 堆叠视图只读。

### 12.4 3D 视图

1. 点击状态栏第四个图标。
2. 显示当前楼层，墙体按真实高度拉伸，并使用墙体材质颜色。
3. 按住左键拖动旋转视角。
4. Layers 面板的 Rotate 和 Tilt 可以精确设置角度。
5. 画布上方的 ↑ 和 ↓ 按钮切换上下楼层：旧楼层先向下（下楼时向上）淡出，新楼层再从另一侧淡入。
6. 也可以使用楼层条直接切换；楼层条是立即切换，不播动画。
7. 3D 视图只读。

## 13. 抬升面

抬升面用于平台、楼梯和坡道。它们会改变热力图和优化器中的客户端高度。

### 13.1 绘制抬升面

1. 打开 Floorplan 标签页。
2. 展开 Raised surfaces。
3. 选择 Platform、Stair 或 Ramp。
4. 选择 Material，或使用 Custom。
5. 设置 Upper height、Thickness。
6. Platform 设置 Height；Stair 和 Ramp 设置 Lower height。
7. Stair 的 N of steps 显示自动计算值，不手工输入。
8. 需要实心底座时打开 Solid base floor。楼梯没有这一项。
9. 点击 Draw raised area。
10. 在画布上点击一个角，再点击对角。
11. 点击 Done 结束。

### 13.2 材质与衰减

预设材质自带衰减值，选择后 Attenuation 显示固定 dB 值。Custom 可以手动输入衰减。

### 13.3 删除抬升面

点击抬升面的边缘选中它，然后按 Delete 或 Backspace。删除多个抬升面时逐个选中删除，不再提供清空全部抬升面的按钮。

## 14. 房间类型与密度

1. 在单层视图右键点击一个房间。
2. 在弹出窗口中搜索房间类型，或从分类列表选择。
3. 设置 Density，单位 devices/m²。
4. 可以输入 Custom label。
5. 点击 Clear 清除该房间的类型和密度覆盖。

房间类型影响覆盖率的密度加权。Room labels 图层控制房间标签显示。

移动端触屏长按房间打开同一窗口。

## 15. 标注

1. 打开 Floorplan 标签页，展开 Notes。
2. 点击 Add note。
3. 在画布上点击位置。
4. 输入标注内容。
5. 点击 Done 保存。
6. 在 Notes 列表点击标注可以选中，点击 Delete note 删除。

按 Esc 取消放置。Notes 图层控制标注显示。

## 16. 撤销、重做与快捷键

### 16.1 撤销与重做

1. Ctrl+Z 撤销。
2. Ctrl+Shift+Z 重做。

撤销覆盖墙体、AP、规划范围、抬升面、材质和标注等编辑。

## 18. 常见问题

### 18.1 热力图不显示

1. 确认 Layers 面板中 Signal heatmap 已打开，或按 H。
2. 确认当前楼层至少有一个 AP。
3. 确认已完成比例标定。
4. 热力图只画到覆盖门限下方 10 dB；如果大片区域没有颜色，说明该处信号确实低于门限。
5. 确认当前在单层或包含热力图的概览视图。

### 18.2 AP 放不下去

1. 确认在单层视图。
2. 确认 Place APs 已打开。
3. Wall mount 需要点击距墙 1 米以内的位置。
4. 范围外点击会被拒绝，除非在优化器设置中打开 Allow APs outside the floor boundary。

### 18.3 覆盖率明显偏低或偏高

1. 检查当前楼层比例是否正确。
2. 检查墙体是否识别完整，墙洞是否过大。
3. 检查规划范围是否覆盖真实楼层。
4. 检查房间类型和密度是否合理。
5. 检查 Coverage threshold 是否与评估标准一致（默认 −70 dBm）。
6. 检查 Propagation 是否按墙体绘制程度选择；墙体已完整绘制时用 Walls drawn in full。高密度办公区还要检查每台 AP 的 Clients 和本层终端估算。

### 18.4 优化器没有改变布局

1. 确认 AP 数量大于零。
2. 确认没有把所有 AP 都 Pin position。
3. 确认当前层墙体、比例和规划范围有效。
4. 多楼层时确认使用的是 Optimize this floor 还是 Optimize all floors。

### 18.5 导出 PDF 后页面是错的楼层

导出期间不要切换楼层或视图。PDF 导出会自动切换楼层截图，操作会打断截图流程。

### 18.6 平面图与下一层对不齐

1. 打开 Floor below 图层查看下一层。
2. 使用 Align X、Align Y 或 Drag to align 调整当前层。
3. 对齐只移动当前层的平面图、墙体、规划范围和 AP。

### 18.7 工程无法导入

1. 确认文件是本程序导出的 .json。
2. 确认文件没有被手动修改或截断。
3. 先新建工程，再重新导入。
4. 导入前导出当前工程，避免覆盖后无法恢复。
